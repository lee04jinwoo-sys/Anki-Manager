# Chinese Deck Systemization & Multi-Language Architecture

## 1. 개요 및 목적
- **목적**: 영문 전용으로 설계되었던 `Anki Manager` 시스템을 확장하여, 중국어 초급(A1~A2, HSK 1~3 기준) 덱을 애플 스타일 템플릿과 자동 링크 시스템으로 완전히 체계화함.
- **주요 대상**:
  - `Chinese Vocabulary` (단어, 뜻, 한어병음, 소리, 품사, 예문, 사진) - 총 699개
  - `Chinese Sentence` (문장, 뜻, 한어병음, 소리) - 총 93개
  - 덱: `1. Language::1.3. Chinese`

---

## 2. 카드 템플릿 사양 (Apple Typography & Pedagogy)
1. **Chinese Vocabulary**:
   - **Card 1 (Cloze Production)**:
     - 앞면: 한글 뜻 + 품사 + 예문 내 대상 단어가 빈칸 마스킹됨.
     - 힌트 규칙: 첫 글자 병음 초성 1글자만 노출 (예: `天气` -> `t___`).
     - **다중 예문 순회 우선 매칭**: 복수 예문 중 단어가 온전히 포함된 예문(Exact Match)을 우선 탐색하여 빈칸 처리.
     - **이합동사(离合词) 분리 마스킹**: 예문에 분리된 형태(`点...菜`)만 있을 경우, `你想[d_]什么[c_]？` 형태로 분리 마스킹 지원.
     - **정답 스포일러 방지**: 매칭 실패 시 예문 박스를 숨김 처리하여 정답 날것 노출 차단.
     - 뒷면: 정답 한자, 성조 표기 한어병음, 원어민 발음 오디오, 앞면과 동일한 예문 및 단어/이합동사 하이라이트 렌더링.
   - **Card 2 (Hanzi Recognition)**:
     - 앞면: 순수 간체자 한자 표기만 제공 (병음/오디오 숨김으로 성조 및 음 독해 강제).
     - 뒷면: 뜻, 품사, 성조 표기 병음, 발음 오디오, 예문 공개 (단어/이합동사 하이라이트).
2. **Chinese Sentence**:
   - **Card 1 (Production)**:
     - 앞면: 순수 한글 뜻만 노출 (불필요한 뱃지/태그 일절 없음)
     - 뒷면: 중국어 문장 + 원어민 소리 자동 재생 + 한어병음
   - **Card 2 (Recognition & Reading)**:
     - 앞면: 순수 중국어 한자 문장만 노출 (소리 및 뱃지 일절 없음 -> 발음/성조 스포일러 차단 및 독해 집중)
     - 뒷면: 중국어 문장 + 원어민 소리 자동 재생 + 한어병음 + 한글 뜻
   - 본문 영역을 시원하게 활용하는 미니멀 레이아웃 유지.
3. **타이포그래피 및 CJK 서체 최적화**:
   - **한자 서체**: Mac 한국어 로케일에서 `-apple-system`에 의해 한국어 고딕(Apple SD Gothic Neo)의 조악한 CJK fallback 한자로 깨지는 문제를 방지하기 위해, 중국어 텍스트(`.zh-text`, `.word`, `.example`, `.zh-sentence`)에 Apple 표준 간체자 서체인 `"PingFang SC"`(苹方)와 `"Hiragino Sans GB"`를 1순위로 강제 적용.
   - **언어 태그 명시**: HTML 요소에 `lang="zh-Hans"` 속성을 명시하여 WebKit 엔진이 중국어 표준 간체자 글리프를 렌더링하도록 강제.
   - **병음 서체**: 성조 기호(`āáǎà` 등) 정렬에 최적화된 `"Avenir Next"`, `"Lucida Grande"`, `"Helvetica Neue"` 전용 서체 스택 적용 및 자간(`letter-spacing: 0.035em`) 미세 조정.
   - **획 선명도 확보**: `.card`의 글로벌 font-weight를 600에서 500으로 정돈하고 표제어 크기를 32px로 확대하여 한자 획 뭉개짐 해결.
4. **다중 예문 동적 순환 (`|||` 포맷)**:
   - 복수 예문이 `|||` 구분자로 저장되어 있으며, 세션별로 앞뒤 카드가 동일한 예문을 동기화하여 표시함.

## 3. 다국어 지원 아키텍처 (Multi-Language Isolation)
1. **SQLite (`data/links.db`)**:
   - `links` 및 `vocab_cache` 테이블에 `lang TEXT DEFAULT 'en'` 컬럼 추가.
   - 영어(`lang='en'`, 8,013단어 / 9,689링크)와 중국어(`lang='zh'`, 699단어 / 313링크)가 완전히 격리되어 저장/조회됨.
2. **백엔드 API (`backend/routers/links.py`)**:
   - `/api/links/stats`, `/api/links/vocab`, `/api/links/scan`, `/api/links/batch-generate` 엔드포인트에 `lang` 파라미터 지원.
3. **프론트엔드 UI (`frontend/src`)**:
   - Header에 세그먼트 컨트롤러(`[ 🇺🇸 English ]` / `[ 🇨🇳 中文 ]`) 제공.
   - 언어 변경 시 `LinkManagerPanel`의 통계, 미연결 어휘 목록, 예문 생성 타겟이 즉시 전환됨.

## 5. 품사 영문 약어 및 HSK 난이도 뱃지 시스템
1. **품사(POS) 영문 표준화**:
   - `v` (동사), `n` (명사), `adj` (형용사), `adv` (부사), `pron` (대명사), `num` (수사), `mw` (양사), `prep` (전치사/개사), `conj` (접속사), `aux` (조동사), `part` (조사), `idiom` (관용구/어구)
   - 데이터베이스 필드 및 템플릿 렌더링을 영어 덱과 1:1 동일한 영문 약어로 일원화.
2. **HSK 난이도 뱃지 (Tags 연동)**:
   - 11,470개 공식 HSK 어휘 데이터를 기반으로 699개 단어 및 92개 문장에 태그 부착:
     - `hsk::1` -> `HSK 1` (파랑, #eff6ff): 단어 304개 (43.5%), 문장 56개 (60.9%)
     - `hsk::2` -> `HSK 2` (하늘, #f0f9ff): 단어 151개 (21.6%), 문장 34개 (37.0%)
     - `hsk::3` -> `HSK 3` (보라, #eef2ff): 단어 101개 (14.4%), 문장 2개 (2.2%)
     - `hsk::4` -> `HSK 4` (주황, #fff7ed): 단어 70개 (10.0%)
     - `hsk::5` -> `HSK 5` (회색, #f8fafc): 단어 32개 (4.6%)
     - `hsk::6` -> `HSK 6` (다크, #f3f4f6): 단어 12개 (1.7%)
   - 예외적 라벨('실용')을 완전히 폐지하고, 파생/합성 어휘(`点菜`, `星期一` 등)를 형태소 기반 난이도로 편입하여 전수 HSK 1~6 단일 체계로 일원화.
